## Pessing Y+U opens the mod menu, to disable, enable, or tweak the mod.
### Check the GitHub release [here](https://github.com/LxVer8/OG-Network-QOL-Mod/tree/main)

# Features:
### Prices & Values:
> 1. Price Tooltip: Shows the "buy" and "sell" prices at the bottom of the tooltip of an item. This only applies to items available on (shop, and items that you can sell in /sell.
> 2. Inventory Value: Displays the total "sell" value of all items in your inventory and open container. You can hover the number to see a list of the most expensive items from that inventory. This only applies to items available on (shop, and items that you can sell in /sell.
> 3. Shulker Box Value: Adds a "Total Value" number to the tooltip of Shulker Boxes, showing the price of all items inside it. This only applies to items available on (shop, and items that you can sell in /sell.
> 4. Ignore Renamed and Custom Items: Skips items that have a different display name to their item ID. This applies to player-renamed items and server-renamed items.
### Runes:
> 1. Rune Level Visualizer: Adds a dot to all Runes to indicate their level based on the possible max level of that Rune. Green dot means its max level, orange means it's a level bellow max, and red means it's two or more levels bellow max.
> 2. Rune Type Visualizer: Changes the texture of paper items used for Runes to have a color based on the kind of Rune (Rare, Legendary, Celestial, Omni and Atral)
> 3. Rune Custom Book Visualizer: Changes the texture of paper items used for Runes to have the texutres of enchanted books from the texture pack you are using. To use this feature you need to have a texture pack that changes the texutre of each enchanted book. This feature is not working properly at the moment.
### Enchants:
> 1. Enchantment Color Fix: Colors the names of enchantments based on their Rune type.
> 2. Enhanced Enchantment Indicator: Adds a "+" at the beginning of an enchantment of its level exceeds the maximum possible for that Rune. A "+" is added for every extra level.
> 3. Overcapped Enchantment Fix: Fixes the broken text on enchantments that go above the vanilla meximum level.
> 4. Convert Roman Numerals: Converta the roman numerals on enchantments to arabic numerals.
### Chat:
> 1. Chat Message Color Remover: Recolors any message in chat to be plain white.
> 2. Chat Name Color Remover: Recolors any name to appear white.
> 3. Chat Rank Remover: Removes all ranks from chat.
> 4. Chat Tag Remover: Removes all tags from chat.
> 5. Real Name Display: Removes the custon names that player can set in chat.
> 6. Server Announcements Remover: Removes the automatic server messages entirely.
### HUD:
> 1. Vote Tracker: Adds a list of all voting websites and how long its left until you can vote again.
> 2. Chat Games Tracker: Adds a text with a countdown until the next RPG ChatGames will happen.
> 3. Seismic Slam Timer: Adds a text that shows the cooldown of Seismic Slam.

# Future ideas:
1. Quest Tracker: It would show on screen the current quests the player and how much they have left from it. If a quest it completed it would show a timer counting the time left for the next quests to be unlocked.
2. Official Item Marker: If an item has the exact enchantment, name, and lore that the original kind of item has, they get a small seal to mark they are legit and not modified. For example, a Faerie Chestplate has Protection I and Unbreaking I. If a chestplate has the same enchantments but no colored name, it won't be marked. If it has a colored name but not the exact same enchantments, it won't be marked. If it has both a colored name and the exact enchantments, it will be marked. This would help find actual original items given by the server over player-make replicas that may have lower enchantments to trick new players into buying them for a higher price.

Shop Information Gatherer: When the command "/qol run StartScanForShops" is sent, the game will automatically, for every single playerwarp listed in /pw, write the command and wait for the player to press enter. There is going to be a message in chat stating an estimated time to scan all playerwarps. Once they arrive, the next command is written automatically, so the player can press enter agian to teleport. While they are teleporting, all stores loaded by the player will be stored and saved (coordenates, price, which item is buying or selling, if it's out of stock, who's shop is it and when it was saved). Once the last playerwarp is reached, a chat message appears with the location of the file with the information about shops. It will be a .txt, so the player can do Ctrl + F to find whatever they are trying to buy or sell. Since this is locally stored, they are free to do whatever they want with the information in it.
31. Spawner Item Mob Visualizer: The head of a mob will appear in the background of the item, allowing you to easily recognize each kind of spawner without having to hover them.

# Disclaimer:
This mod is not dynamic to the updates that the server may go though, meaning that if any of the items from the shop changes, the mod will not update itself to show the new numbers. The same thing applies in the case of a new item being added, an old item getting removed, or new Runes being created.
This mod is hardcoded to apply to all items, no matter the server or world you are in, meaning that you will see this on a single player world, or any other server you play, as long as you have the mod activated.
