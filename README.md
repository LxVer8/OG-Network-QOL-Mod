# Important:
This mod is published in Modrinth at [OG-Network QOL Mod](https://modrinth.com/mod/og-network-qol). This repository was made to have an easier way for people that are interested on the code to look at it without having to download anything.

# Features:
- Price Tooltip: Every single item in the game will have a small tooltip addition that states the cost to buy and sell on the /shop. This also applies when hovering a Shulker Box full of items.
- Full Inventory Value: Any inventory will show a number with the value of all the items inside it. Hovering the number will show the most valuable items from it. This applies to your inventory as well.
- Rune Type Visualizer: Based on the kind of Rune (Celestial, Omni or Astral) the color of the item will change to make them easier to recognize.
- Rune Level Visualizer: Basen on the level of a Rune (I, II, III, and so on) a dot will appear in it. Green means the Rune is max level, orange means it is a level bellow max level, and red means that is anything bellow 2 levels from being max.

# Future ideas:
1. Quest Tracker: It would show on screen the current quests the player and how much they have left from it. If a quest it completed it would show a timer counting the time left for the next quests to be unlocked.
2. Price Tooltip 2.0 + Full Inventory Value 2.0: Right now, all items get tracked. Price Tooltip 2.0 would make it so items that can not be moved by the player don't get a tooltip with the price, nor get calculated to the inventory price. Same applies for custom made items, like a Beautyberry.
3. Official Item Marker: If an item has the exact enchantment, name, and lore that the original kind of item has, they get a small seal to mark they are legit and not modified. For example, a Faerie Chestplate has Protection I and Unbreaking I. If a chestplate has the same enchantments but no colored name, it won't be marked. If it has a colored name but not the exact same enchantments, it won't be marked. If it has both a colored name and the exact enchantments, it will be marked. This would help find actual original items given by the server over player-make replicas that may have lower enchantments to trick new players into buying them for a higher price.
4. OakHeven Tracker: It would track whats the current OakHaven event, how long it has left, and show when the next one will happen and which event will be.
5. Language Support: Self explanatory. It would allow the information displayed by the mod to adapt based on the language Minecraft is set in.
6. AFK Shard/Key Counter: It would have an on-screen counter with the current amount of AFK Shards and AFK Keys the player has.

# Disclaimer:
This mod is not dynamic to the updates that the server may go though, meaning that if any of the items from the shop changes, the mod will not update itself to show the new numbers. The same thing applies in the case of a new item being added, an old item getting removed, or new runes being created.
This mod is hardcoded to apply to all items, no matter the server or world you are in, meaning that you will see this on a single player world, or any other server you play, as long as you have the mod activated.
