## Pessing Y+U opens the mod menu, to disable, enable, or tweak the mod.
### Check the Modrinth release [here]([https://github.com/LxVer8/OG-Network-QOL-Mod/tree/main](https://modrinth.com/mod/og-network-qol))

# Features:
### Prices & Values:
> 1. Vanilla Price Tooltip: Shows the "buy" and "sell" prices at the bottom of the tooltip of an item. This only applies to items available on (shop, and items that you can sell in /sell)
> 2. OakHaven Price Tooltip: Shows the "sell" prices at the bottom of the tooltip of an item. This only applies to OakHaven items.
> 3. Vanilla Inventory Value: Displays the total "sell" value of all items in your inventory and open container. You can hover the number to see a list of the most expensive items from that inventory. This only applies to items available on (shop, and items that you can sell in /sell.
> 4. OakHaven Inventory Value: Displays the total "sell" value of all OakHaven items in your inventory and open container. You can hover the number to see a list of the most expensive items from that inventory. This only applies to OakHaven items.
> 5. Vanilla Shulker Box Value: Adds a "Total Value" number to the tooltip of Shulker Boxes, showing the price of all items inside it. This only applies to items available on (shop, and items that you can sell in /sell.
> 6. OakHaven Shulker Box Value: Adds a "Total Value" number to the tooltip of Shulker Boxes, showing the price of all OakHaven items inside it. This only applies to OakHaven items.
> 7. Ignore Renamed and Custom Items: Skips items that have a different display name to their item ID. This applies to player-renamed items and server-renamed items.
> 8. Theoretical Sell Price: Shows the "sell" price for items that can't be sold in /sell as they are, but could be turned into something that can be sold (for example a Diamond Block uncrafted into Diamonds)
### Runes:
> 1. Rune Level Visualizer: Adds a dot to all Runes to indicate their level based on the possible max level of that Rune. Green dot means its max level, orange means it's a level bellow max, and red means it's two or more levels bellow max. A special case is done for Runes that go above their normal level, displaying a purple dot instead.
> 2. Rune Type Visualizer: Changes the texture of paper items used for Runes to have a color based on the kind of Rune (Rare, Legendary, Celestial, Omni and Atral)
> 3. Rune Success Visualizer: Displays the success perfentage on the bottom side of all Runes as a line; the longer the line, the more success rate.
### Enchants:
> 1. Enchantment Color Fix: Colors the names of enchantments based on their Rune type.
> 2. Enhanced Enchantment Indicator: Adds a "+" at the beginning of an enchantment of its level exceeds the maximum possible for that Rune. A "+" is added for every extra level.
> 3. Overcapped Enchantment Fix: Fixes the broken text on enchantments that go above the vanilla meximum level.
> 4. Convert Roman Numerals: Converts the roman numerals on enchantments to arabic numerals.
### Chat:
> 1. Chat Message Color Remover: Recolors any message in chat to be plain white.
> 2. Chat Name Color Remover: Recolors any name to appear white.
> 3. Chat Rank Remover: Removes all ranks from chat.
> 4. Chat Tag Remover: Removes all tags from chat.
> 5. Real Name Display: Removes the custom names that player can set in chat.

### HUD:
> 1. Vote Tracker: Adds a list of all voting websites and how long its left until you can vote again.
> 2. Chat Games Tracker: Adds a text with a countdown until the next RPG ChatGames will happen.
> 3. Seismic Slam Tracker: Adds a text that shows the cooldown of Seismic Slam.
> 4. OakHaven Flight Tracker: Adds a small text showing the flight time left and cooldown for the OakHaven Armor set. Only appears when in OakHaven.
> 5. OakHaven Boss Slayer Quest: Shows the current Boss Slayer quest (Jack) in the OakHaven Quest Tracker. Only appears when in OakHaven.
> 6. OakHaven Foraging Quest: Shows the current Foraging quest (Alice) in the OakHaven Quest Tracker. Only appears when in OakHaven.
> 7. OakHaven Merchant Quest: Shows the current Merchant quest (Lily) in the OakHaven Quest Tracker. Only appears when in OakHaven.
> 8. OakHaven Mining Quest: Shows the current Mining quest (Trent) in the OakHaven Quest Tracker. Only appears when in OakHaven.
> 9. OakHaven Mob Slayer Quest: Shows the current Mob Slayer quest (Cassie) in the OakHaven Quest Tracker. Only appears when in OakHaven.
> 10. Daily Quest Tracker: Shows your pending Daily Quests and their progress. Open /quests once so it can read them. Appears everywhere except OakHaven.
> 11. Quest Tracker Style: Select the visual style of the OakHaven and Daily Quest Trackers.

# Future ideas:
1. Official Item Marker: If an item has the exact enchantment, name, and lore that the original kind of item has, they get a small seal to mark they are legit and not modified. For example, a Faerie Chestplate has Protection I and Unbreaking I. If a chestplate has the same enchantments but no colored name, it won't be marked. If it has a colored name but not the exact same enchantments, it won't be marked. If it has both a colored name and the exact enchantments, it will be marked. This would help find actual original items given by the server over player-make replicas that may have lower enchantments to trick new players into buying them for a higher price.
2. Language Support: Self explanatory. It would allow the information displayed by the mod to adapt based on the language Minecraft is set in.
3. AFK Shard/Key Counter: It would have an on-screen counter with the current amount of AFK Shards and AFK Keys the player has.
4. Welcome Notification: A sound effect will appear whenever a new player joins, allowing you know when to welcome them even if you have the game minimized. This would not type the name for you or tell you who to welcome, you still have to do everything yourself.
5. Full Number Display: Display the entire number instead of an abreviation. For example in the scoreboard with your money or claim blocks, when a Auto Sell Chest shows your earnings, /baltop, and so on.
6. Overwrite Notification Time: Allows the user to set a new amount of time they want notifications to last (notifications refer to the big text on screen that appears, for example, when a restart is set, when you come back from being AFK, or when you sell something in /sell) to overlap the Minecraft limit, both to make them last longer or shorter.
7. Leaderboard Reset Tracker: Tracks how long it's left until the leaderboard resets.
8. Average Earnings Calculator: By sending a command in the chat it will calculate your earnings gotten with Auto Sell Chests. You can select an amount of money you would like to estimate how long it would take until you obtain it by using a different command.
9. Remove Vote Messages: Hides the messages that appear when someone votes for the server. You can decide if it removes yours as well or not.
10. Remove OakHaven Messages: Hides the messages related to OakHaven.
11. Default Join Messages: Replaces all the custom join and leave messages with the default one.
12. Rune Enchantment Visualizer: Replace the default paper of a Rune for a custom texture for each Rune. The texture would represent what the Rune does, like Fire Aspect having fire, or Dolphin Master having the dorsal fin of a dolphin. The Rune Type Visualizer feature would be reworked to either make a thin outline around the custom texture, add a dot on the bottom-left corner (like the one used on the Rune Level Visualizer), or to not show anything at all.

18. Spawener Radius Visualizer: Display a sphere around any spawners that are near by the player that marks the edge where the spawner is going to be loaded.
19. Tunneling Area Visualizer: When holding a pickaxe with Tunneling and looking at a block, a bit area will be marked, representing the zone that will be mined with Tunneling.
20. Rune Function Fix: Adds a short text on each Rune stating what it does.
21. Rune Function Command: Adds a command (/qol runes) that will list every single Rune. When sent with the name of a Rune, it will send a short explanation about what that Rune does.
22. Shop Information Gatherer: When the command "/qol run StartScanForShops" is sent, the game will automatically, for every single playerwarp listed in /pw, write the command and wait for the player to press enter. There is going to be a message in chat stating an estimated time to scan all playerwarps. Once they arrive, the next command is written automatically, so the player can press enter agian to teleport. While they are teleporting, all stores loaded by the player will be stored and saved (coordenates, price, which item is buying or selling, if it's out of stock, who's shop is it and when it was saved). Once the last playerwarp is reached, a chat message appears with the location of the file with the information about shops. It will be a .txt, so the player can do Ctrl + F to find whatever they are trying to buy or sell. Since this is locally stored, they are free to do whatever they want with the information in it.
23. Spawner Item Mob Visualizer: The head of a mob will appear in the background of the item, allowing you to easily recognize each kind of spawner without having to hover them.
24. OakHaven Custom Armor Color: Allows the user to select a custom color for their OakHaven Armor. It would only apply to the small green parts of it.
25. No Custom Items Models: When disabled, turns off any custom model that weapons and armors may have.
26. No Custom Mobs Models: When disabled, turns off any custom model that mobs may have.

# Disclaimer:
This mod is not dynamic to the updates that the server may go though, meaning that if any of the items from the shop changes, the mod will not update itself to show the new numbers. The same thing applies in the case of a new item being added, an old item getting removed, or new Runes being created.
This mod is hardcoded to apply to all items, no matter the server or world you are in, meaning that you will see this on a single player world, or any other server you play, as long as you have the mod activated.
